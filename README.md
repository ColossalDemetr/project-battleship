# Battleship project

Everybody knows the game called 'Battleship', right? Here it is, written using JavaScript for you (minimal version) to play. Not only that - it's accessible via browser. You can play either versus CPU or versus your bully 😛

# How to run

### Node:

Download the project, run `npx serve`. You're battle ready ⚔️

### VS Code

Download the project, and use **Live Server** or **Live preview** extensions to run it.
